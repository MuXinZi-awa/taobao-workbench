# 推广监控（tg-monitor）

淘宝万相台（关键词推广）监控与批量投放台。

## 功能
- **登录态大灯**：`_dual_one --headless` 探测（万相台 headless 拿不到 csrf，用淘宝侧判登录）；「检测登录」按钮手动触发（自动 probe 会抢 chrome_profile，已禁用）
- **11 计划组容量看板**：真名 + 实时容量（批运行时自动更新 plan_state）
- **推广工程区**（与监控区隔离）：
  - 单品精准推广（料号 / 淘宝 ID）
  - 批量推广（拖 csv，或默认池按数量）
  - 数量可调、随时停止
- **默认池进度**：共 4284 / 已跑 / 剩余 + 本次批料号清单
- **起停批**：PID 文件方案（tasklist 检测——跑批状态可靠）
- **对账**：推广记录 vs 万相台实际单元，ID 双体系（老单元宝贝 ID / 新推推广池）+ 标题桥兜底

## 数据文件
- 推广记录：`推广记录.csv`（权威全集）
- 计划状态：`plan_state`（容量）
- 运行日志：`tg_panel.log`（插件 log 字段 → 运行日志 Tab 可看）

## 依赖脚本
- `tuiguang_auto.py` / `_batch_tg.py` / `_tg_scheduler.py`（推广一键跑仓）
- 登录态：`chrome_profile`（万相台独立登录域，账号 `duopeier:运营`）

# 流水线插件（pipeline）v0.2 设计

> 上品/优化/推广 一条龙状态机。Zip 化插件，同查双百规格。

## 数据流与分流逻辑（梓帆 0907 确认）
```
拖 csv / 输料号(或ID)
 → 查询（API 按料号搜）
    ├─ 找得到品 = 老品 → 查双百分数
    │    ├─ 双百 → 跳过（除非 force 强制处理）
    │    └─ 没双百 → 走优化流
    └─ 找不到品 = 新品 → 走上新流
 → 素材整理（清点: 封面/主图/规格书/视频 缺啥补啥）
 → 【人工审核，整批机制】：
    逐张看素材 → 左右切换 → 标记：放行 / 有水印→AI送修 / 质量差→换源重找
    可反悔（改标记）→ 一批全部审完 → 才提交处理（不即时提交）
    AI 送修回来 → 【人工复检】走同一套审核（老板铁律: 水印检测不可信，素材全人工过）
 → 上品(新品) / 优化(老品补属性素材) → 推广(万相台)
```

## UI
- **工作区 Tab（pipeline 面板）**：
  - 输入框：料号 或 淘宝 ID（单量回车）
  - 拖入 csv（批量）→ 自动识别料号列 → 逐行跑
  - 表格上方**阶段灯**：查询→素材→人工审核→上品/优化→推广 五盏 + 当前处理品名（批量高亮行）
  - 表格列：料号 | ID | 标题 | 类型(上新/优化/跳过) | 素材 | 人工审核 | 上品/优化 done | 推广 done
- **素材审核视图**：图片大图 + 左右切换（←/→）+ 标记按钮（放行/AI送修/换源）——已标记可反悔重标；一批审完统一提交
- 日志：批量"当前处理的料号"高亮显示

## 状态
- 独立 state：`plugins/pipeline/state.json`（逐料号：类型/双百/阶段/素材标记/审核结果/时间戳）——断点续
- 只读引用现有产物（推广记录.csv / 素材目录 / 没双百清单）——不覆盖

## 与现有脚本边界（铁律）
- server.py **调用层**：调现成函数/脚本（商品查询 API、素材清点、fetch_attrs、tuiguang_auto 等）
- 不改 publish_auto 等底层逻辑；脚本路径 sys.path 引 `推广一键跑/`

## 版本
- v0.1.0：拖 csv/输料号 → 素材清点 + 推广记录 → 表格 + 阶段灯（面板可跑 0907）
- v0.2 规划：查询分流(找到=优化/没找到=上新 + 双百跳过)、素材整批人工审核(切换/反悔/统一提交)、AI 送修复检

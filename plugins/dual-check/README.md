# 查双百 插件（v2）

查商品是否达双百（基础分 100 + 扶优分 100）。API 直查，非页面抓取。

## 支持的操作

### 单查
1. 左栏点「查双百」→「单查」
2. 填**料号**（必填，API 按料号搜，如 `1379668`）；淘宝ID 可选
3. 点「查」→ 结果 + 处理建议

### 批量
1. 切「批量」→ 拖入表格（**csv / xlsx / xls 都行**）
2. 自动识别料号列（表头含"料号/型号/编码/part"等；找不到就猜第一列）——**别人丢来的原始表也能直接用**
3. 点「开始批量查」→ 逐行查，显示**进度条 + 当前行**，可停止
4. 结束出**总结**：双百几个 / 未双百几个（列清单 + 处理建议）

## 结果怎么看

| 结果 | 含义 | 怎么办 |
|---|---|---|
| 已双百 | 基础分+扶优分满 | 无需处理，可放心投放 |
| 未双百（提扶优分） | 缺必填属性 | 发布页补全（接口/品牌/型号/类别/认证/适用），属性可爬 TE 官网/renhotecrf |
| 未双百（素材类） | 无视频 / 主图缺失 | 传视频（make_video）与主图（图库/AI 送修/TE官网图）；无视频不双百 |
| 查询失败 | 登录态失效/超时 | 重新登录 chrome_profile（打开一次千牛/万相台）后重试 |

## 说明

- 双百 = 基础分100（选对分区）+ 扶优分100（必填属性填全）——和质量/素材无关
- 批量用前端 SheetJS 解析表格（开源库，本地 vendor/）——不上传你的表到任何地方

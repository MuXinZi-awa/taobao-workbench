# AI 主图（xyq-img）

料号 → 模板渲染 → 参考图 → 主图。走**小云雀 Seedream 5.0 Lite，不花积分**。

## 用法

1. 填料号（如 `0462-201-16141`）
2. 选模板（现在有 `主图_Y2K.md`）
3. 选模型：**Lite（免费）** 默认；Pro 更精细但花积分
4. 「看提示词」先确认会拿什么去画 → 「生成主图」

参考图**自动**从素材目录取（`办公室工作\素材\产品素材\<料号>\`，优先"换源_待复检"，其次"封面"）。

## 模板怎么加

模板和字段定义都在 `plugins\pipeline\scripts\`：

```
prompt_templates\主图_Y2K.md     ← 版面模板（{料号} {品牌} {品类} {品类要点} {标题} {尺寸}）
prompt_templates\品类要点.json    ← 各品类"哪些必须一致"（连接器/芯片/保险丝/服装…）
_xyq_prompt.py                    ← 字段来源映射（属性清单列名 → 占位符）
```

- **加版面**：在 `prompt_templates\` 放一个新 `.md`，面板下拉自动出现；
- **加品类**：在 `品类要点.json` 补一条，模板不用动；
- **字段来源**：`办公室工作\数据\属性清单.csv`（列名映射在 `_xyq_prompt.py` 的 `COL2FIELD`）。

## 为什么不用写死提示词

版面是共用的，变的只有品牌/料号/品类这类字段。字段缺了会**显式标"缺"，不编造**
（宁可提示词里缺一块，也不能让模型自己编一个品牌上去）。

## 边界

- **只做调用层**：生图客户端 `_xyq_api.py`、模板引擎 `_xyq_prompt.py` 都在 pipeline 插件的 scripts 里，本插件不改它们；
- **参考图是硬前提**：没找到就直接报错，不允许纯文字生成（元器件靠丝印和结构识别，AI 凭空画会被一眼看穿）；
- **文字是重灾区**：模板里已写死"每处文字逐字一致、不得增减改写"，且不画条形码（扫不出来＝假信息）。

## 依赖

- 小云雀登录态：`工具\_xyq_login.py` 扫码一次（存在 `推广一键跑\chrome_profile`）；
- 代理：`127.0.0.1:7897`（下载产物必须走）；
- 原理与踩坑详见 `工具\运维经验_小云雀免费生图.md`。

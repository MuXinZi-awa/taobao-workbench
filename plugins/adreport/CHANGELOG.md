# CHANGELOG · 报表（adreport）

> 本文件依据 `manifest.json`、`README.md`、`_运维经验_推广素材插件_0908.md`、workbench 内核 `CHANGELOG.md`（插件版本跳变行）补记。
> 版本号只写有明确出处者；无出处的改动标「未记载」，不臆测。

## 0.2.9 — 2026-09-17
- 趋势解读跟随所选范围：后端加 `insightByRange`（7/30/all 各一份）+ `insightCustom`，与区间表同源同窗口；面板按 MODE 取对应那份，标题右侧标当前范围。

## 0.2.8 — 2026-09-16
- 区间表改读「按日明细」：新增 `_win(tag)` / `_range_plans` / `_range_scenes`，从 `plan_daily`/`scene_daily` 按区间聚合，与 KPI/走势同源；窗口一律截至昨天（T+1）。

## 0.2.7 — 2026-09-16
- 修「今日」KPI 与下方表不同源：`today_total` 改为优先从 `tag='today'` 场景快照汇总，无快照回退 `daily` 今天行。

## 0.2.6 — 2026-09-15
- 修落库 ts 混格式（date-only 串压住完整时间戳）导致面板恒取旧批。
- 修 KPI 卡字段名写错（`alipayInshopAmt` → `amt`，`num`/`cart` 同理）导致成交额/笔数/加购恒为 0。

## 0.2.5 — 2026-09-14
- 报表去 JSON：数据全走库（带 `account` 列），修切号串台。
- 采集口径改 T+1（历史截至昨天）；今日场景/计划落库（`tag='today'`）。
- 刷新分流加缺口检测（近 30 天）+ 新鲜度检测；日期窗口改按天 + 缺日补 0。

## 0.2.4 — 2026-09-10
- 面板改按「激活连接」取数；切号即隔离（有存档秒刷新 / 没存档清空）。
- `report_db` 新增 `get_plans()` / `get_scenes()`。

## 0.2.3 — 2026-09-10
- 面板顶部加账户标识（连接名 · memberID · 数据天数 · 采集时间），动态跟随激活连接。
- 加账户一致性自查（连接表 `member_id` 列）+ 不一致红字告警。

## 0.2.2 — 2026-09-10
- 修读取侧账号兜底漏洞（取不到 memberId 时放开全库 → 多账号串台）：新增 `_resolve_account(raw)`，取不到账号不查库。

## 0.2.1 — 2026-09-10
- 报表数据入库累积（`推广一键跑/report_db.py` → `runtime/report.db`：`daily`/`plan_snap`/`scene_snap`）；读取优先走库。

## 2026-09-10（首版，版本号未记载）
- 新增插件「报表」：万相台报表台——账户概览 10 指标 / 推广计划(11) / 营销场景 / 日走势；指标可点切走势、本期比上期、随范围联动。
